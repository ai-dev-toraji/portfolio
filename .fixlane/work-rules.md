# このリポジトリで、AI が触ってよい場所

このファイルは FixLane（サイト修正の仕組み）から呼ばれる AI が読むための地図です。
**リポジトリの作りを知っているのはこのリポジトリ自身**なので、場所の指定はここに置きます。
FixLane 側には、どのリポジトリにも当てはまる決まり（依頼された箇所以外を触らない等）だけを置きます。

---

## 1. このリポジトリの作り

```
/
├─ app/                  ページ。Next.js の App Router
│  ├─ (home)/ about/ service/ contact/   各ページ
│  ├─ layout.tsx         全ページ共通の外枠
│  └─ globals.css        サイト共通のスタイル（色や寸法の変数を含む）
├─ components/
│  ├─ layout/            ヘッダー・フッターなどの共通の枠
│  └─ ui/                ボタン・見出しなどの共通の部品
├─ public/               画像やアイコンなどの静的ファイル
├─ app/api/ と api/      処理の窓口（見た目ではない）
├─ proxy.ts              経路の設定
└─ next.config.ts        ビルドの設定
```

記事や作品の中身は **microCMS（管理画面）** から来ます。このリポジトリには入っていません。

---

## 2. 変更してよい場所

- **`app/` の中**（`app/api/` を除く）… ページの文言・見た目
- **`components/` の中** … 共通の部品。**ただし §4 の決まりに従うこと**
- **`public/` の中のファイル** … 画像などの差し替え

それ以外の場所は、下に書いていなくても変更しないでください。

---

## 3. 🔴 変更してはいけない場所（理由つき）

### `app/api/` と `api/`

見た目ではなく**処理**です。外部サービスの資格情報を扱う経路も含みます。

### `next.config.ts` / `proxy.ts` / `postcss.config.mjs` / `eslint.config.mjs`

ビルドと経路の設定です。壊すとサイト全体が出なくなります。

### `package.json` / ロックファイル

依存する道具の一覧です。勝手に増やしたり版を変えたりしないでください。

### `.github/` と **`.fixlane/`（このファイル自身）**

仕組みそのものです。

### 管理画面（microCMS）にある内容

作品や記事の本文・画像の多くは管理画面側にあります。コードを直しても変わりません。
そこを指す依頼が来た場合は、コードを変更せず「管理画面から直せます」と報告してください。

---

## 4. 共通の部品と共通の変数の扱い

### 共通の部品（`components/` の中）

**複数のページから使われています。** 1か所の見た目を変えたいときに、
**部品を使うのをやめて中身を写し取る、という直し方はしないでください。**
他のページと切り離されて、次の修正から取り残されます。

値を渡す口が無い場合は、**既定の動きを今までどおりに保ったまま口を足し、
依頼された場所からだけ別の値を渡してください。**

### 共通の変数（色・寸法・間隔）

サイト共通の指定（`app/globals.css` の変数や Tailwind の設定）で決まっている値を、
**その場限りの直接の値（`#1234AB` など）に置き換えないでください。**
濃さや大きさを変える必要があるときも、共通の指定の仕組みの中で行ってください。

> この2つは、実際に事故が起きた箇所です。見た目は依頼どおりに変わり、検査も通ったのに、
> サイトの作りが壊れていました。

---

## 5. 変更したあと

変更をコミットしたら、そこで作業を終えてください。
ビルドや表示の確認を自分で行う必要はありません（確認は後続の検査が自動で行います）。
